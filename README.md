# رادار (Radar) — مشخّص الشبكة والراوتر
تطبيق أندرويد (Kotlin + Compose) يحدد موضع المشكلة: الرابط اللاسلكي، الراوتر، المزود، DNS، أم تضخم المخزن.

## البناء السحابي
1. أنشئ مستودعًا على GitHub وارفع محتويات هذا المجلد.
2. تبويب Actions > Build APK (يعمل تلقائيًا عند الدفع).
3. بعد النجاح: Artifacts > Radar-debug-apk. وإن فشل: نزّل test-reports أو انسخ سجل الخطأ.

لا يوجد gradlew في المشروع؛ يستخدم الـWorkflow Gradle 8.9 عبر setup-gradle.
